## 🎯 Project Overview

**Mojaz+** is an AI-powered system designed to streamline the processing of traffic violation objections. The system provides two main interfaces:

| Interface | Description |
|-----------|-------------|
| **👨‍💼 Absher Employee** | Dashboard for managing and reviewing objections with AI analysis |
| **👤 Citizen** | Simple interface for submitting objections and attaching evidence |

---

## ✨ Key Features

### 🤖 Artificial Intelligence
- **Text Analysis**: Analyzes objection text to determine strength and acceptance probability
- **Image Analysis**: Examines attached evidence and evaluates quality
- **Priority Sorting**: Automatically ranks objections by importance (High - Medium - Low)
- **Mojaz+ Assistant**: Smart chatbot to answer citizen inquiries

### 📊 Employee Dashboard
- Comprehensive objection statistics
- Filtering and categorization
- Separate tabs for pending and processed objections
- Full details with approve/reject functionality

### 📝 Citizen Interface
- Easy objection submission form
- Upload up to 3 images as evidence
- Auto-generate sample objection text for testing
- Real-time analysis before submission

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/maznalharbi/Mojaz.git

# Navigate to directory
cd Mojaz

# Install dependencies
npm install

# Start development server
npm start
```

App runs at: `http://localhost:3000`

## 🎯 فكرة المشروع

**مُوجَّز+** هو نظام ذكي يهدف إلى تسهيل وتسريع عملية معالجة اعتراضات المخالفات المرورية باستخدام الذكاء الاصطناعي. يوفر النظام واجهتين رئيسيتين:

| الواجهة | الوصف |
|---------|-------|
| **👨‍💼 موظف أبشر** | لوحة تحكم لإدارة ومراجعة الاعتراضات مع تحليل ذكي |
| **👤 المواطن** | واجهة سهلة لرفع الاعتراضات وإرفاق الأدلة |

---

## ✨ المميزات الرئيسية

### 🤖 الذكاء الاصطناعي
- **تحليل النصوص**: تحليل نص الاعتراض وتحديد قوته ومدى احتمالية قبوله
- **تحليل الصور**: فحص الأدلة المرفقة وتقييم جودتها
- **ترتيب الأولويات**: ترتيب الاعتراضات تلقائياً حسب الأهمية (عالي - متوسط - منخفض)
- **مساعد موجز+**: شات بوت ذكي للإجابة على استفسارات المواطنين

### 📊 لوحة تحكم الموظف
- عرض إحصائيات شاملة للاعتراضات
- فلترة وتصنيف الاعتراضات
- تبويبات منفصلة للاعتراضات المعلقة والمعالجة
- تفاصيل كاملة لكل اعتراض مع إمكانية القبول أو الرفض

### 📝 واجهة المواطن
- نموذج سهل لرفع الاعتراضات
- إمكانية إرفاق حتى 3 صور كأدلة
- توليد نص اعتراض تلقائي للتجربة
- تحليل فوري للاعتراض قبل الإرسال
